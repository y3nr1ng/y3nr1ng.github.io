SimScope

Virtual optical benches with explicit physical models and inspectable simulation results.

An optical simulation needs to explain which physical setup was modeled, how light was represented numerically, and what the resulting measurements actually mean. A visually convincing plot is not enough to establish a correct result.

I develop SimScope, a Python toolkit for virtual microscopes and optical benches. Experiments combine placed components with ray or field representations, then record paths, detector measurements, and fields for browser inspection.

The library separates physical configuration from numerical sampling and execution. That distinction makes it possible to refine a calculation without silently changing the experiment, and to inspect a recorded result without repeating the entire solve. Ray tracing, scalar propagation, and vector focusing have different assumptions; the model is selected according to the question being asked.

Reference comparison

A Michelson interferometer test compares the simulated detector distribution with an independently calculated Gaussian propagation reference. It checks whether the optical model reproduces an expected distribution for that configuration, rather than judging the result by how convincing a plot looks.

The test specifies a relative-error tolerance of 2%. That is an acceptance criterion in the test, not a measured result reported here. It does not establish accuracy for arbitrary optical systems. Sampling convergence and model limitations are separate checks.

The source repository is private. The project combines optical modeling with software for inspecting the resulting measurements and fields.
