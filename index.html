Systems

  • Infrared laser-scanning microscopy

    UIUC · Bhargava Lab · Control software and firmware

    My primary work is control software and firmware for infrared laser-scanning microscopes. I also contribute to electrical design and build, align, integrate, and maintain the instruments.

    Related software: ScopeEngine / ciMicroscope

    Related publications:

    • Designing software solutions for infrared chemical imaging and digital pathology (SPIE proceedings, 2025)
    • Sensitive Discrete Frequency Mid-Infrared Absorption Spectroscopy Using Digitally Referenced Detection (Analytical Chemistry, 2024)
    • Infrared spectroscopic laser scanning confocal microscopy for whole-slide chemical imaging (Nature Communications, 2023)

  • Light-sheet microscopy

    Academia Sinica · Acquisition tools and volumetric processing

    I have worked with axial-scan, dual-view, and lattice light-sheet systems. My contributions include acquisition tools, volumetric image-fusion methods, and processing pipelines for large microscopy datasets.

    Related software: uToolbox, DeconvLR

    Related publications:

    • Optogenetic manipulation of cell migration with high spatiotemporal resolution using lattice lightsheet microscopy (Communications Biology, 2022)
    • Rapid high resolution 3D imaging of expanded biological specimens with lattice light sheet microscopy (Methods, 2020)
    • Two-beam interference lattice lightsheet for structured illumination microscopy (Journal of Physics D, 2020)

  • Single-molecule microscopy

    System design and image analysis

    I contributed to single-molecule microscopy system design. My related computational work includes localization processing and geometric analysis of 3D super-resolution datasets.

    Related publications:

    • Rapid single-wavelength lightsheet localization microscopy for clarified tissue (Nature Communications, 2019)
    • Lightsheet localization microscopy enables fast, large-scale, and three-dimensional super-resolution imaging (Communications Biology, 2019)

  • Microscopy computing cluster

    Academia Sinica · Cluster setup and processing workflows

    I established a multi-server cluster for large microscopy datasets, supporting distributed image processing and storage.

    Related software: Dask on TORQUE, ThunderSTORM cluster scripts

  • Department network infrastructure

    NTU CSIE · Team lead, network administration (221)

Selected projects

  • ScopeEngine / ciMicroscope

    I develop a microscope acquisition framework and desktop application, separating acquisition workflows from vendor drivers and transferring acquired data through shared memory.

    Earlier microscope software and demonstration

  • not-envi

    I develop a browser-based hyperspectral viewer with linked image and spectrum analysis. A C/WebAssembly core manages a bounded data cache so the whole input need not stay in memory.

    Open the viewer

  • SimScope

    I develop a Python toolkit for virtual optical benches, separating physical configuration from numerical sampling and recording ray paths, fields, and detector measurements for inspection.

    Reference-comparison example
